# 1. Composició del sistema

El sistema informàtic de PackGo servirà per organitzar els paquets que arribin als punts de repartiment de cada poble. La idea és que sigui més fàcil per als treballadors gestionar els paquets de les grans empreses, com Amazon. Amb aquest sistema es podran registrar els paquets, guardar les seves dades i preparar els repartiments.
Perquè tot funcioni, PackGo necessitarà hardware i software.

## Hardware

- **Ordinador:** s'utilitzarà al punt de repartiment per controlar els paquets, veure les seves dades i organitzar els repartiments.
- **Mòbils o tablets:** els faran servir els treballadors per saber quins paquets han de repartir i on els han de portar.
- **Lector de codis de barres:** servirà per llegir els codis dels paquets i guardar la seva informació més ràpidament.
- **Impressora:** servirà per imprimir etiquetes dels paquets o altres documents que facin falta.

## Software

- **Programa de gestió de paquets:** serà el programa principal de PackGo. Servirà per registrar els paquets, consultar les seves dades i organitzar els repartiments.
- **Base de dades:** guardarà la informació de cada paquet, com el nom del destinatari, l'adreça, el codi del paquet i si ja ha estat entregat.
- **Sistema per organitzar els paquets:** ajudarà a separar els paquets segons les adreces i a preparar els repartiments.
- **Sistema d'usuaris:** servirà perquè cada treballador pugui entrar al programa amb el seu usuari.

# 2. Estructura del sistema

Quan les grans empreses de repartiment portin els paquets a PackGo, els treballadors els registraran amb el lector de codis de barres. D'aquesta manera, les dades de cada paquet quedaran guardades a la base de dades.
Quan ja estiguin registrats tots els paquets, el programa els ordenarà segons les adreces dels clients. Així serà més fàcil saber quins paquets s'han de repartir a cada zona i preparar el repartiment de cada treballador.
Després, els repartidors podran mirar des del mòbil o la tablet quins paquets han de portar i a quines adreces han d'anar. Quan entreguin un paquet, podran canviar el seu estat al programa perquè quedi marcat que ja ha arribat al destinatari.
El sistema funcionarà de la següent manera:

- L'ordinador permetrà utilitzar el programa de gestió.
- El lector de codis de barres servirà per registrar els paquets.
- El programa guardarà les dades a la base de dades.
- El sistema organitzarà els paquets segons les seves adreces.
- Els mòbils o tablets permetran als repartidors consultar els paquets i actualitzar el seu estat.
- La impressora servirà per imprimir etiquetes o documents.
  
Tot això servirà perquè els treballadors tinguin la informació dels paquets més a mà i puguin organitzar millor els repartiments. També ajudarà a evitar errors i a saber en tot moment on es troba cada paquet.

# 3. Entorn del sistema

El sistema informàtic de PackGo tindrà diferents usuaris que l'utilitzaran per fer les seves tasques.

Els usuaris seran:

- **Administrador:** serà l'encarregat de controlar el sistema. Podrà consultar els paquets, organitzar els repartiments i gestionar els treballadors.
- **Treballadors del punt de repartiment:** s'encarregaran de rebre els paquets, escanejar-los, registrar-los al sistema i preparar-los per al repartiment.
- **Repartidors:** utilitzaran els mòbils o les tablets per veure quins paquets han de repartir, mirar les adreces i marcar els paquets com a entregats.
- **Grans empreses de repartiment:** portaran els paquets fins als punts de PackGo. La informació que donin sobre els paquets serà necessària per poder registrar-los al sistema.
- **Clients:** podran consultar com va el repartiment dels seus paquets per saber si ja han estat entregats o quan els arribaran.

L'objectiu de PackGo és que tots aquests usuaris puguin treballar millor i que els paquets estiguin ben organitzats. D'aquesta manera, serà més fàcil repartir-los i aconseguir que arribin als seus destinataris.
