#1. Composició del sistema
El sistema informàtic de PackGo servirà per organitzar els paquets que arribin al punt de repartiment de cada poble i facilitar la feina dels treballadors. La idea és que el sistema pugui registrar els paquets, guardar la informació de cada un i ajudar a organitzar els repartiments automàticament.
El sistema estarà format per diferents components de hardware i software.
##Hardware:
Ordinador: s'utilitzarà al punt de repartiment per gestionar els paquets, consultar la informació i organitzar els repartiments.
Mòbils o tauletes: els utilitzaran els treballadors per consultar quins paquets han de repartir i veure les dades dels destinataris.
Lector de codis de barres: servirà per escanejar els codis dels paquets i registrar-los més fàcilment.
Impressora: servirà per imprimir etiquetes o informació dels paquets si és necessari.
##Software:
Programa de gestió de paquets: serà el programa principal de PackGo. Servirà per registrar els paquets, consultar-ne la informació i organitzar els repartiments.
Base de dades: guardarà tota la informació dels paquets, com el destinatari, l'adreça, el codi del paquet i el seu estat.
Sistema d'organització dels repartiments: servirà per agrupar els paquets segons la seva destinació i ajudar a decidir com s'han de repartir.
Sistema d'usuaris: permetrà que cada treballador accedeixi al sistema i utilitzi les funcions que necessiti segons la seva feina.
#2. Estructura del sistema
Els diferents components del sistema estaran connectats entre ells per poder treballar conjuntament.
Quan les grans empreses deixin els paquets al punt de repartiment, un treballador els registrarà al sistema informàtic mitjançant el lector de codis de barres. D'aquesta manera, la informació de cada paquet quedarà guardada a la base de dades.
Una vegada registrats tots els paquets, el programa de gestió consultarà la base de dades i organitzarà els paquets segons les adreces dels destinataris. Així serà més fàcil preparar els repartiments i decidir quins paquets ha de portar cada treballador.
Després, els treballadors podran consultar des del mòbil o la tauleta quins paquets han de repartir i a quines adreces han d'anar. Quan entreguin un paquet, podran actualitzar-ne l'estat perquè quedi registrat al sistema que ja ha estat entregat.
Per tant, els components funcionaran de la següent manera:
L'ordinador permetrà utilitzar el programa de gestió.
El lector de codis de barres enviarà la informació dels paquets al programa.
El programa guardarà i consultarà les dades de la base de dades.
El sistema d'organització prepararà els repartiments.
Els mòbils o tauletes permetran als treballadors consultar els repartiments i actualitzar l'estat dels paquets.
La impressora permetrà imprimir etiquetes o informació quan sigui necessari.
Tots aquests components estaran relacionats perquè la informació dels paquets estigui actualitzada i els repartiments es puguin organitzar correctament.
#3. Entorn del sistema
El sistema informàtic de PackGo tindrà diferents usuaris que interactuaran amb ell per fer les seves tasques.
Els principals usuaris seran:
Administrador: serà l'encarregat de gestionar el sistema, consultar tots els paquets, controlar els repartiments i gestionar els treballadors.
Treballadors del punt de repartiment: s'encarregaran de rebre els paquets, escanejar-los, registrar-los i preparar-los per al repartiment.
Repartidors: utilitzaran els mòbils o les tauletes per consultar els paquets que han de repartir, veure les adreces i actualitzar l'estat dels lliuraments.
Grans empreses de repartiment: seran les encarregades de portar els paquets fins al punt de repartiment de PackGo. La informació dels paquets serà necessària per poder registrar-los al nostre sistema.

També hi haurà una relació amb els habitants dels pobles, ja que seran els destinataris dels paquets, encara que no necessàriament hauran d'utilitzar directament el sistema informàtic.

L'objectiu és que tots aquests usuaris puguin utilitzar el sistema per fer la seva feina més fàcil i aconseguir que els paquets estiguin ben organitzats i arribin als seus destinataris.
