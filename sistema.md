# 1. Composició del sistema
El sistema informàtic de PackGo servirà per organitzar els paquets que arribin al punt de repartiment de cada poble i fer mes facil la feina dels treballadors. La idea és que el sistema pugui registrar els paquets, guardar la informació de cada un i ajudar a organitzar els repartiments automàticament.
El sistema tindra hardware i software.
## Hardware:
Ordinador: s'utilitzarà al punt de repartiment per gestionar els paquets, veure la informació i organitzar els repartiments.
Mòbils o tablets: els utilitzaran els treballadors per veure quins paquets han de repartir i veure les clients.
Lector de codis de barres: servirà per escanejar els codis dels paquets i registrar-los més rapid.
Impressora: servirà per imprimir etiquetes o informació dels paquets.
## Software:
Programa de gestió de paquets: serà el programa principal de PackGo. Servirà per registrar els paquets, veure la informació i organitzar els repartiments.
Base de dades: guardarà tota la informació dels paquets, com el destinatari, l'adreça, el codi del paquet i el seu estat.
Sistema d'organització dels repartiments: servirà per agrupar els paquets i decidir com s'han de repartir.
Sistema d'usuaris: permetrà que cada treballador entri al sistema.
# 2. Estructura del sistema
Quan les grans empreses deixin els paquets al punt de repartiment, un treballador els posara al sistema informàtic amb el lector de codis de barres. Així la informació de cada paquet quedarà guardada a la base de dades.
Una vegada registrats tots els paquets, el programa de gestió mirara la base de dades i organitzarà els paquets per les adreces dels clients. Així serà més fàcil preparar els repartiments i decidir quins paquets ha de portar cada treballador.
Després, els treballadors podran consultar des del mòbil o la tablet quins paquets han de repartir i a quines adreces han d'anar. Quan entreguin un paquet, podran actualitzar l'estat perquè quedi registrat al sistema que ja ha estat entregat.
Resum rapid de com funcionara tot:
L'ordinador permetrà utilitzar el programa de gestió.
El lector de codis de barres enviarà la informació dels paquets al programa.
El programa guardarà i mirara les dades de la base de dades.
El sistema d'organització prepararà els repartiments.
Els mòbils o tablets els utilizaran els treballadors per mirar els repartiments i actualitzar l'estat dels paquets.
La impressora imprimira etiquetes o informació.
Tots aixo servira perquè la informació dels paquets estigui actualitzada i els repartiments es puguin organitzar correctament.
# 3. Entorn del sistema
El sistema informàtic de PackGo tindrà diferents usuaris que l'utilizaran per fer la seva feina.
Els usuaris seran:
Administrador: gestionara el sistema, consultar tots els paquets, portar els repartiments i gestionar els treballadors.
Treballadors del punt de repartiment: s'encarregaran de rebre els paquets, escanejar-los, registrar-los i preparar-los per al repartiment.
Repartidors: utilitzaran els mòbils o les tablets per veure els paquets que han de repartir, veure les adreces i actualitzar l'estat dels enviaments.
Grans empreses de repartiment: portan els paquets fins al punt de repartiment de PackGo. Nececitarem la informació dels paquets per poder registrar-los al nostre sistema.
També els clients, podran utilizar el sistema per veure com va el repartiment, encara que no estan obligats a utilitzar directament el sistema informàtic.

L'objectiu és que tots aquests usuaris puguin utilitzar el sistema per fer la seva feina més fàcil i aconseguir que els paquets estiguin ben organitzats i arribin als seus destinataris.
